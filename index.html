چرا JAMINTRA؟

هدف، ساخت یک سایت نمایشی دیگر نیست؛ هدف ایجاد زیرساختی است که بتواند از محتوای آموزشی و خدمات تخصصی شروع کند و در ادامه به سیستم مدیریت مزرعه، هوش مصنوعی، GIS، IoT و بازار خدمات کشاورزی توسعه پیدا کند.

اصل امنیت

اطلاعات حساس کاربران، کلیدهای API و دسترسی‌های مدیریتی نباید در کد عمومی GitHub قرار بگیرند. Backend و سیاست‌های دسترسی باید جداگانه پیاده‌سازی شوند.
